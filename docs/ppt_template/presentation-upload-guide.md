# 발표 자료 업로드 안내

발표 자료는 주차별로 정리해 `docs/ppt_template`에 업로드합니다.

## 업로드 방식

- 주차별 폴더를 만들고 해당 주차의 발표 자료를 모아둡니다.
- 각 팀은 발표 자료를 편집 가능한 `.pptx` 형식으로 업로드합니다.
- 파일명에는 주차와 팀을 구분할 수 있는 정보를 포함합니다.

## 예시

```text
docs/ppt_template/
└── week11/
    ├── team1.pptx
    ├── team2.pptx
    └── team3.pptx
```

## 참고

- 발표 자료는 이후 다른 팀이 참고할 수 있도록 가능한 한 원본 `.pptx` 파일로 공유합니다.
- 별도 폰트를 사용한 경우, 발표 자료가 깨지지 않도록 폰트 정보도 함께 공유합니다.
