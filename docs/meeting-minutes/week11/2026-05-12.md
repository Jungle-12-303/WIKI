# 팀장 회의록 — 2026-05-12 (화)

**참석자:** 우현, 호석, 다애, 재환, 범진, 정연, 혜연

**주제:** 중요 안건 결정 방식, 반회의 운영 방식

| 안건 | 결정 상태 | 결정 내용 |
|------|-----------|-----------|
| 중요 안건 결정 방식 | 결정 | 반 전체에 영향을 주거나 강제되는 안건은 각 팀장이 팀원들의 의견을 먼저 취합한 뒤, 팀장 회의에서 논의하고 다수결로 결정하기로 함. |
| 반회의 운영 방식 | 결정 | 기존 반회고는 삭제하기로 함. |
| 자율 안건 공유 방식 | 결정 | 반 전체에 강제되지 않는 안건은 안건을 제안한 사람이 자율적으로 Slack에 올려 공유하기로 함. |
| 반장 역할 범위 | 결정 | 반장은 반 전체에 강제되는 안건만 팀장 회의에서 결정하는 역할을 맡기로 함. |

## 논의 내용

- 반회의처럼 중요한 안건은 팀원들의 의견을 먼저 물어보고, 의견을 취합한 뒤 결정해야 한다는 의견이 제안됨.
- 반회의를 선택적으로 진행할지, 강제적으로 진행할지, 장소와 진행 방식은 어떻게 할지 논의함.
- 강제적인 안건(ex반 전체 커밋션 같은)이 있을 때 어떤식으로 진행할지 논의함
- 요청한 사람이 직접 안건을 올릴지, 반장 또는 팀장이 안건을 취합해 올릴지 논의함.
- 팀장 회의에서 결정해야 하는 안건은 팀별 의견을 모은 뒤 팀장끼리 결정하되, 최종적으로는 다수결을 사용할 수밖에 없다는 의견이 있었음.
- 반 전체적으로 정해야 하는 안건만 반장 회의에서 다루는 방향으로 정리함.

## 결정된 안건

- 반회고는 삭제함.
- 반 전체 커밋 컨벤션처럼 반 전체에 강제되는 안건이 아니라면, 안건이 있는 사람이 각자 Slack에 올리는 방식으로 진행함.
- 강제되는 안건은 팀장이 팀원의 의견을 취합한 뒤, 팀장 회의에서 다수결로 결정함.
- 선택적인 안건(ex 반회고)이 있을시 그사람이 주도적으로 진행하는 식으로 결정됨
